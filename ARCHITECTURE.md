# ARCHITECTURE

Версия: 1.0

Данный документ описывает техническую архитектуру проекта.

Любое изменение структуры сайта должно соответствовать этому документу.

==================================================

# Главный принцип

Архитектура должна быть простой.

Каждый файл отвечает только за одну задачу.

Запрещается создавать файлы, выполняющие несколько несвязанных функций.

==================================================

==================================================

# Главный принцип компонентов

Каждый компонент существует независимо.

Компонент нельзя проектировать с расчётом только на одну страницу.

Любой компонент должен иметь возможность использоваться повторно.

==================================================

# Повторное использование

Если одинаковый код встречается дважды —

он должен стать компонентом.

Если одинаковый CSS встречается дважды —

он должен быть объединён.

Если одинаковый JavaScript встречается дважды —

он должен стать общей функцией.

==================================================

# Запрещается

Копировать большие блоки кода.

Дублировать CSS.

Дублировать JavaScript.

Использовать разные стили для одинаковых элементов.
