# CONTRIBUTING

## Rules

`AGENTS.md` is the authoritative contributor constraint for repository changes.

In particular, contributors must not perform refactoring, optimization, architecture changes, or unrelated cleanup unless the current task explicitly requests or authorizes that work.

Project goals and architectural documents describe desired outcomes; they do not grant permission to modify unrelated code.

When documentation conflicts with `AGENTS.md`, follow `AGENTS.md` and resolve the documentation conflict in a separate documentation task.
