# PROJECT

## 1. Цель проекта

Цель проекта

Создать эталонный B2B-сайт производителя мебельных опор VELES LEGS на платформе InSales.

Проект должен отвечать следующим требованиям:

• максимальная скорость загрузки;
• максимально простая поддержка;
• стабильная работа после обновлений InSales;
• единый стиль оформления;
• высокая конверсия;
• соответствие современным требованиям SEO;
• соответствие требованиям Schema.org;
• соответствие требованиям Accessibility;
• отсутствие дублирования кода;
• модульная архитектура.

Главная задача проекта — создать систему, которую можно развивать годами без полной переделки.

Каждый элемент сайта должен быть независимым модулем.

Любое изменение должно затрагивать только тот модуль, который изменяется.

Любое решение должно быть масштабируемым.

Проект не допускает временных решений, костылей и дублирования логики.

Качество архитектуры важнее скорости разработки.

## 2. Философия проекта

Данный проект создаётся не как обычный интернет-магазин.

Это долговечная промышленная платформа производителя мебельных опор.

Главные принципы проекта:

• скорость выше эффектов;
• стабильность выше красоты;
• простота выше сложных решений;
• отсутствие дублирования кода;
• отсутствие временных решений;
• каждое изменение должно улучшать архитектуру;
• каждая функция должна быть понятной;
• минимальная зависимость от платформы;
• отсутствие хаотичных стилей;
• отсутствие конфликтующих CSS;
• отсутствие дублирующихся JavaScript;
• отсутствие магических чисел;
• единая система именования.

Сайт должен оставаться обслуживаемым через 5, 10 и более лет.

Любое изменение сначала оценивается по следующим вопросам:

1. Делает ли это архитектуру проще?
2. Делает ли это сайт быстрее?
3. Делает ли это код понятнее?
4. Не создаёт ли это будущих проблем?

Если хотя бы один ответ отрицательный — изменение запрещено.
