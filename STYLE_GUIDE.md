# STYLE GUIDE

Версия: 1.0

Этот документ определяет единый визуальный стиль проекта Veles Legs.

Ни один компонент сайта не может нарушать правила данного документа.

Все новые элементы обязаны соответствовать STYLE_GUIDE.md.

--------------------------------------------------

# Основная идея дизайна

Стиль сайта —

современный промышленный минимализм.

Сайт должен вызывать доверие к производителю.

Посетитель должен ощущать:

• надежность;

• качество;

• спокойствие;

• профессионализм;

• аккуратность.

--------------------------------------------------

# Запрещается

Запрещено использовать:

• кислотные цвета;

• яркие градиенты;

• мигающие элементы;

• бесполезные анимации;

• визуальный шум;

• декоративные элементы без функции;

• тяжелые тени;

• стеклянный дизайн;

• неоморфизм;

• элементы, ухудшающие читаемость.

--------------------------------------------------

# Основные цвета

Белый — основной фон.

Черный — основной акцент.

Серый используется только для второстепенной информации.

Красный используется исключительно для ошибок.

Зеленый используется исключительно для успешных действий.

# Типографика

В проекте используются только два шрифта.

Основной текст:

Montserrat

Используется для:

• описаний;

• кнопок;

• характеристик;

• меню;

• карточек товара;

• форм.

Заголовки:

Playfair Display

Используется только для:

• H1;

• H2;

• крупных акцентных заголовков.

# Правила

Никогда не использовать более двух шрифтов.

Никогда не использовать декоративные шрифты.

Никогда не использовать CAPS LOCK для длинных текстов.

Допускается верхний регистр только:

• на кнопках;

• в коротких подписях.

# Скругления

Используются только следующие значения:

0 px

6 px

8 px

12 px

16 px

24 px

30 px

Запрещается использовать случайные значения.

--------------------------------------------------

# Тени

Тени используются минимально.

Допускаются только лёгкие тени.

Запрещены:

• тяжёлые размытия;

• цветные тени;

• множественные тени;

• внутренние тени без необходимости.

--------------------------------------------------

# Рамки

Основной стиль:

1 px solid #000

или

2 px solid #000

Толстые рамки применяются только для выделения важных элементов.

--------------------------------------------------

# Иконки

Использовать единый стиль.

Толщина линий должна быть одинаковой.

Нельзя смешивать outline и filled иконки.

# Анимации

Анимации используются только тогда, когда они помогают пользователю.

Они никогда не должны отвлекать.

Допускаются:

• hover;

• fade;

• плавное появление;

• плавное изменение цвета;

• плавное изменение прозрачности.

Не допускаются:

• мигание;

• подпрыгивание;

• бесконечные циклы;

• вращение элементов без причины;

• агрессивные масштабирования.

Стандартная скорость:

0.2s

0.3s

0.4s

Использовать easing:

ease

или

ease-in-out

--------------------------------------------------

--------------------------------------------------

# Производительность

Любое изменение интерфейса должно учитывать:

CLS

LCP

FID

INP

Не допускается:

смещение элементов после загрузки;

скачки размеров;

мигание изображений;

резкая смена высоты блоков.
